HOW TO READ
----------------------------------------------------------------------------------------------------
  Set tiers (move tiers from moves_by_tier.txt v3, shown in brackets after each move):
    Tier 1 sets  (early game)     : Tier 1 moves + at most one Tier 2 move. Neutral nature. No item or a basic berry.
    Tier 2 sets  (early-mid game) : Tier 2 + Situational moves + at most one Tier 3 move. Reasonable but imperfect
                                    nature (attackers often use Lonely / Hasty / Mild...). Simple items: Sitrus, type boosters...
    Tier 3 sets  (mid-late game)  : Tier 3 + Situational moves + at most one Tier 4 move. Optimal nature.
                                    Solid items: Leftovers, Muscle Band, Expert Belt, Rocky Helmet, Lum Berry...
    Tier 4 sets  (bosses, player) : Best mix of Tier 3, Tier 4 and Situational moves. Competitive items (Life Orb, Choice...).
    Exception (v3): Tier 3 and Tier 4 sets may use a Tier 2 [Pivot] move (U-turn, Volt Switch, Flip Turn).
    Entry hazards do not exist in this game (v3), so no set uses them. Eviolite is banned from the game.
  Set A / Set B follow the Pokémon profile shown under its name:
    Mixed attacker: A = Physical / B = Special.   Balanced / Bulky: A = Defensive / B = Offensive.
    Pure Defensive: A = Pure Stall / B = Defensive with utility.
    Offensive (one attacking stat): A = Setup / power attacker / B = second offensive role (pivot, priority, Choice, utility).
  Every move is legal for that Pokémon (current or past learnset, incl. pre-evolution moves). Smeargle may use any move
  (Sketch). Every set was checked by script for move legality, tier rules, ability legality and item rules.
