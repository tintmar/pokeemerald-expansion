# Talents secrets : talents forts que le révélateur de talents (salle ROOM_CONTENT_SECRET_ABILITY) peut proposer à un
# Pokémon, en plus de ceux de son espèce. Régénérer src/data/isaac_secret_abilities.h :
#     python3 tools/isaac/build_secret_abilities.py
#
# Format : TALENT  ADÉQUATION  [TYPE]   (# commentaire)
# L'adéquation dit comment juger si le talent va au Pokémon (IsaacPickSecretAbilities, src/isaac_pokemon.c), d'après
# ses attaques, ses stats et ses types (Pierre Prisme comprise) :
#   CONTACT PUNCH BITE SLICE PULSE SOUND RECOIL MULTIHIT  attaques offensives qui profitent du talent
#   SECONDARY  attaques avec un effet secondaire          WEAK_MOVES  attaques de puissance 60 ou moins
#   LOW_ACC    attaques de précision < 90 %               STAB        attaques de ses types
#   SELF_DROP  attaques qui baissent ses stats (pénalisé par ses attaques qui les augmentent)
#   TYPE t     attaques du type t (+ si c'est un des siens)
#   NORMALIZE t  attaques Normal, qui deviennent du type t (+ si c'est un des siens)
#   WEATHER t  météo qui renforce le type t : attaques de ce type, et le Pokémon de ce type
#   PHYSICAL / SPECIAL  attaquant de cette catégorie      ATTACKER  tout attaquant
#   STATUS_MOVES  attaques de statut                      HEALING     attaques de soin
#   BULK       Pokémon défensif                           FRAIL       Pokémon fragile
#   RESIST t [t2]  faiblesse à ces types (x2, x4)        WEAKNESSES  nombre de faiblesses
#   SPEED      Pokémon rapide et offensif                 SLOW        Pokémon lent
#   ANY        utile à tous
# Au plus 64 talents utilisés (VAR_ISAAC_SECRET_ABILITY_SEEN_* : un bit par talent déjà proposé dans la descente).
